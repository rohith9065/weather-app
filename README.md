# WeatherNow - Weather Forecast Web App

A responsive weather application built with HTML, CSS and JavaScript.

## Features

- Search weather by city
- Current weather information
- 5-day forecast
- Celsius/Fahrenheit unit conversion
- Browser location support
- Dynamic OpenWeatherMap weather icons
- Responsive mobile design
- Error handling for invalid cities

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- Browser Geolocation API

## Setup

1. Create an account at OpenWeatherMap.
2. Get an API key from the API section.
3. Open `script.js`.
4. Replace:

```javascript
const API_KEY = "YOUR_OPENWEATHERMAP_API_KEY";
```

5. Open `index.html` in a browser.

For best results, run it using VS Code Live Server.
